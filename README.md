## 🚀 Projetos em destaque

### 📊 [InfoCombustível Brasil — Pipeline de Dados e Dashboard sobre Preços de Combustíveis (2018–2025)](https://github.com/Finnagun/pipeline-precos-combustiveis-anp)
Pipeline de ponta a ponta sobre a Série Histórica de Preços de Combustíveis da ANP: ingestão via KNIME, armazenamento e modelagem em PostgreSQL, tratamento e EDA em Python, e dashboard interativo publicado no Power BI.  
**Stack:** KNIME · PostgreSQL · Python (pandas, seaborn) · Power BI  
🔗 [Dashboard publicado](https://tinyurl.com/52nf6vf9)

### 🏥 [Jornada do Paciente na UTI](https://github.com/Finnagun/jornada-paciente-uti-sql)
Projeto 100% autoral: banco de dados relacional (SQLite) com dados sintéticos de pacientes de UTI, consultas SQL avançadas, 9 views e um dashboard interativo de 3 páginas no Power BI.  
**Stack:** SQL · SQLite · Power BI  
🔗 [Dashboard publicado](https://app.powerbi.com/view?r=eyJrIjoiZTY3ODJkN2QtNTIzZi00MDBkLWEwYWQtY2IzZmJmOTZiZTUzIiwidCI6IjExZGJiZmUyLTg5YjgtNDU0OS1iZTEwLWNlYzM2NGU1OTU1MSIsImMiOjR9)

### 🌐 [Mercado Brasileiro de Dados — Tech Challenge FIAP (Fase 3)](https://github.com/Finnagun/bigdata_data_hackers)
Pipeline de Engenharia de Dados e Analytics na AWS, construído em grupo durante a Pós-Graduação. Ingestão em camadas Bronze/Silver/Gold via AWS Glue e PySpark, catalogação com Glue Crawler, consultas via Athena, e dashboard executivo no Power BI sobre o perfil dos profissionais de dados no Brasil.  
**Stack:** Python · PySpark · SQL · AWS Glue · Amazon S3 · Amazon Athena · Power BI  
🔗 [Dashboard publicado](https://app.powerbi.com/view?r=eyJrIjoiYTQ5Njc3ZmMtZWMzZS00YzdhLTg1ODEtZDM5NmMyNzdhZjJlIiwidCI6IjExZGJiZmUyLTg5YjgtNDU0OS1iZTEwLWNlYzM2NGU1OTU1MSIsImMiOjR9&pageName=19cb90bfbb0d3f66f956)
